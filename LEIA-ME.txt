2. COMO PEGAR O ID DO PIXEL DA META
-----------------------------------
 1. Entre no Gerenciador de Eventos da Meta (business.facebook.com) com a
    conta do cliente.
 2. Conectar fontes de dados → Web → dê o nome "Endo Evolution".
 3. Escolha instalar o código manualmente e copie só o número do Pixel.
    Não precisa colar o código: o site já tem.
 4. Cole em META_PIXEL_ID.


3. COMO PEGAR O ID DO GOOGLE ANALYTICS
--------------------------------------
 1. Entre em analytics.google.com com a conta Google do cliente.
 2. Administrador → Criar → Propriedade → "Endo Evolution",
    fuso de Brasília, moeda Real.
 3. Crie um fluxo de dados Web com o endereço do site.
 4. Copie o "ID da métrica" (G-XXXXXXXXXX) e cole em GA4_ID.
 5. Depois dos primeiros acessos, em Administrador → Eventos, marque como
    "evento principal": enviou_formulario (quem enviou o formulário).


4. O QUE É MEDIDO (guia em linguagem simples)
---------------------------------------------
Cada coisa que o visitante faz vira um "evento" no Google Analytics. Os nomes
estão em português e cada evento traz um detalhe (o "parâmetro"), também
em texto legível.

 Evento no Analytics   O que significa                        Detalhe que vem junto
 -------------------   ------------------------------------   -----------------------------------
 page_view             Abriu o site                           (automático)
 viu_secao             Chegou numa parte da página            secao: "3. O que o método resolve"...
 leu_pagina            Rolou a página até certo ponto         percentual: "25%", "50%", "75%", "100%"
 clicou_inscricao      Clicou num botão de inscrição          local: "Menu do topo", "Primeira tela
                                                              (topo)", "Depois de O que o método
                                                              resolve" ou "Chamada final"
 enviou_formulario     ENVIOU o formulário (é o lead!)        local: qual botão trouxe a pessoa
 abriu_duvida          Abriu uma pergunta das dúvidas         pergunta: o texto da pergunta
 video_assistido       Ligou o som do vídeo do professor      progresso: "Ligou o som", "25%"... "100%"
 clicou_instagram      Clicou no Instagram                    local: "Rodapé" ou "Página de obrigado"

 No Meta Pixel (quando o ID for colocado): PageView, ViewContent (chegou na
 inscrição), CliqueInscricao, Lead (enviou o formulário), AssistiuVideo,
 CliqueInstagram.

 FUNIL PRINCIPAL (o que olhar primeiro):
   visitantes → viu_secao "11. Inscrição" → clicou_inscricao → enviou_formulario

 DE ONDE VEM CADA LEAD:
   Use links com utm nos anúncios e na bio, por exemplo:
   https://endoevolution.com.br/?utm_source=instagram&utm_medium=bio
   O site repassa esses utm (e o botão clicado) para o formulário do Tally.

 CONFIGURAÇÕES QUE PRECISAM ESTAR FEITAS:
   a) No Tally → Settings → "Redirect on completion":
      https://endoevolution.com.br/obrigado.html?botao=@botao
      (o @botao é o campo oculto; digite @ no Tally para inserir)
   b) No Tally, crie campos ocultos (/hidden) com os nomes:
      utm_source, utm_medium, utm_campaign, utm_content, utm_term, botao
   c) No Google Analytics → Administrador → Definições personalizadas,
      dimensões de evento: local, percentual, secao, pergunta, progresso.
   d) No Google Analytics → Administrador → Eventos: marcar
      enviou_formulario como "evento principal" (a estrela).
   e) A página obrigado.html tem os mesmos IDs no fim do arquivo. Se trocar
      o ID do Analytics ou colocar o do Pixel, troque nos dois arquivos.
